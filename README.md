# 舆情协同 Agent Demo

面向舆情部门与事业部的双角色工作流演示，覆盖：

- 上游供应商舆情总表导入
- 事业部粘贴链接并由 Agent 生成标准申请
- 统一事件池与 Agent 智能研判
- 责任事业部与对接人匹配
- 在线协商、处理方案与任务分发

## 本地运行

需要 Node.js 22.13 或更高版本。

```bash
npm install
npm run dev
```

启动后访问终端显示的本地地址。

## Demo说明

当前监测结果、传播量、文章内容和 Agent 判断均为模拟数据。本项目主要用于确认业务流程和界面交互，真实上线还需接入供应商监测接口、网页解析服务、媒体库、组织人员数据及企业身份认证。
